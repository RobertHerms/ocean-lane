# Ocean Lane walkthrough

A first-person walkthrough of a split-level house, built with three.js and baked lighting.

Open the site and press **Start walking**.

| Keys | Action |
| --- | --- |
| ↑ / ↓ | Walk forward / back |
| ← / → | Turn (hold Shift to sidestep) |
| PgUp / PgDn | Look up / down (or drag with the mouse) |
| Space | Open / close a door |
| M · H · C | Map · help · level your view |

It needs a desktop browser with WebGL 2 (Chrome, Edge or Firefox) and a reasonable graphics card.
